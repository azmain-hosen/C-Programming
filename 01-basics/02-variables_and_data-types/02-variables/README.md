# Variables in C

This section covers variable declaration, initialization, assignment, reassignment, constants, multiple variables, and variable naming rules in C programming.

Each example demonstrates how variables are created, assigned values, and used in a C program.

## Topics Covered

### 1. Variable Declaration

**File:** `01-declaration.c`

- Declaring variables using data types such as `int`, `float`, `double`, and `char`.
- Understanding how variables are declared before assigning values.

### 2. Variable Initialization

**File:** `02-initialization.c`

- Declaring a variable and assigning its initial value in the same statement.
- Initializing variables of different data types.

### 3. Variable Assignment

**File:** `03-assignment.c`

- Assigning values to previously declared variables.
- Using the assignment operator (`=`).
- Working with integer, floating-point, and character variables.

### 4. Variable Reassignment

**File:** `04-reassignment.c`

- Updating a variable's value after its initial assignment.
- Understanding how reassignment changes the value stored in a variable.

### 5. Multiple Variables

**File:** `05-multiple_variables.c`

- Using multiple variables in a single program.
- Combining different data types to represent student information.
- Displaying variable values using `printf()`.

### 6. Constant Variables

**File:** `06-const_variable.c`

- Declaring a constant using the `const` keyword.
- Initializing a constant variable.
- Understanding that a constant object cannot be modified through that variable after initialization.

### 7. Variable Naming Rules

**File:** `07-variable_naming.c`

- Choosing meaningful variable names.
- Using letters, digits, and underscores in identifiers.
- Understanding why a variable name cannot begin with a digit.
- Avoiding spaces, hyphens, and reserved keywords in variable names.
