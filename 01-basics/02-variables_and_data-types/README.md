# Variables and Data Types

This section covers the fundamental concepts of variables and data types in C programming.

## Topics Covered

### Basic Data Types

* Integer (`int`)
* Floating-point (`float`)
* Double precision (`double`)
* Character (`char`)
* Boolean (`bool`)
* Void (`void`)

### Variables

* Variable declaration
* Variable initialization
* Variable assignment
* Variable reassignment
* Multiple variables
* Constant variables (`const`)
* Variable naming rules

### Type Modifiers

* `signed`
* `unsigned`
* `short`
* `long`
* `long long`

### Type Ranges

* `sizeof()`
* `INT_MIN`
* `INT_MAX`
* `UINT_MAX`
* Integer storage size and value range

### Practice

The `05-type-practice` folder contains practical examples that combine the concepts learned in this section.
