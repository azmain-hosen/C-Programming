# Variables and Data Types in C

This section covers the fundamental concepts of variables and data types in C programming, including variable declaration, initialization, type modifiers, integer ranges, and practical examples.

## Topics Covered

### 1. Basic Data Types

- Integer (`int`)
- Floating-point (`float`)
- Double-precision floating-point (`double`)
- Character (`char`)
- Boolean (`bool`)
- Void (`void`)

### 2. Variables

- Variable declaration
- Variable initialization
- Variable assignment
- Variable reassignment
- Working with multiple variables
- Constant variables using `const`
- Variable naming rules

### 3. Type Modifiers

- `signed`
- `unsigned`
- `short`
- `long`
- `long long`

### 4. Type Ranges

- The `sizeof` operator
- `INT_MIN`
- `INT_MAX`
- `UINT_MAX`
- Integer storage size and value ranges

### 5. Practical Exercises

The `05-type-practice` folder contains a student information program that combines multiple data types, variable initialization, constants, Boolean values, and formatted output.

## Learning Objectives

After completing this section, learners should be able to:

- Identify and use fundamental C data types.
- Declare, initialize, assign, and reassign variables.
- Understand constants and variable naming rules.
- Use type modifiers and inspect integer value ranges.
- Use appropriate format specifiers with `printf()`.
- Apply these concepts in practical C programs.

## Purpose

The goal of this section is to build a strong foundation in how C represents different kinds of data, stores values in variables, and handles integer types and their ranges.
