# Basic Data Types in C

This section introduces basic data types and the `void` function concept in C programming. Each example demonstrates how to declare variables, assign values, and display results using `printf()`.

## Topics Covered

### 1. Integer (`int`)

**File:** `01-integer.c`

- Declaring an integer variable.
- Assigning an integer value.
- Displaying an integer using `%d`.

### 2. Float (`float`)

**File:** `02-float.c`

- Declaring a floating-point variable.
- Storing a decimal value.
- Using `%.2f` to display two digits after the decimal point.

### 3. Double (`double`)

**File:** `03-double.c`

- Declaring a double-precision floating-point variable.
- Storing a decimal value with more precision.
- Displaying the value using `printf()`.

### 4. Character (`char`)

**File:** `04-character.c`

- Declaring a character variable.
- Storing a single character using single quotes.
- Using `%c` to display a character.

### 5. Boolean (`bool`)

**File:** `05-boolean.c`

- Including the `<stdbool.h>` header.
- Using `true` and `false` values.
- Displaying Boolean values as `1` and `0` using `%d`.

### 6. Void (`void`)

**File:** `06-void.c`

- Defining a function with the `void` return type.
- Using `void` in the parameter list to indicate no parameters.
- Calling a function that performs an action without returning a value.

## Concepts Practiced

- Variable declaration and initialization

## Learning Objectives

After completing this section, learners should be able to:

- Identify and use basic C data types.
- Declare variables and assign values.
- Choose suitable format specifiers for output.
- Understand the use of Boolean values.
- Understand how `void` is used in function declarations and definitions.

## Purpose

The goal of this section is to build a foundation in C data types and prepare for more advanced topics such as variables, type modifiers, type ranges, and type conversions.
