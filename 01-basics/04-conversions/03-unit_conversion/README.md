# Unit Conversion in C

This section contains C programming examples for converting between common measurement units. Each program demonstrates basic arithmetic operations, user input, and formatted output.

## Topics Covered

### 1. Length
Conversions between kilometer, meter, centimeter, and millimeter.

- Kilometer to meter
- Meter to kilometer
- Meter to centimeter
- Centimeter to meter
- Meter to millimeter
- Millimeter to meter

### 2. Mass
Conversions between kilogram, gram, and milligram.

- Kilogram to gram
- Gram to kilogram
- Kilogram to milligram
- Gram to milligram

### 3. Time
Conversions between hours, minutes, and seconds.

- Hour to minute
- Minute to hour
- Minute to second
- Second to minute

### 4. Speed
Conversions between kilometers per hour and meters per second.

- Kilometers per hour to meters per second
- Meters per second to kilometers per hour

### 5. Area
Conversions between square meters and square centimeters.

- Square meter to square centimeter
- Square centimeter to square meter

### 6. Volume
Conversions between liters and milliliters.

- Liter to milliliter
- Milliliter to liter
