# Number System Conversion in C

This section contains C programs for converting integers between four common number systems: Decimal, Binary, Octal, and Hexadecimal.

Each program demonstrates number representation, conversion techniques, input validation, and formatted output.

## Number Systems Covered

| Number System | Base | Digits Used |
|---|---:|---|
| Decimal | 10 | 0–9 |
| Binary | 2 | 0–1 |
| Octal | 8 | 0–7 |
| Hexadecimal | 16 | 0–9, A–F |

## Conversions Covered

### 1. Decimal Conversions
- Decimal to Binary
- Decimal to Octal
- Decimal to Hexadecimal

### 2. Binary Conversions
- Binary to Decimal
- Binary to Octal
- Binary to Hexadecimal

### 3. Octal Conversions
- Octal to Decimal
- Octal to Binary
- Octal to Hexadecimal

### 4. Hexadecimal Conversions
- Hexadecimal to Decimal
- Hexadecimal to Binary
- Hexadecimal to Octal

## Concepts Practiced

- Integer data types and character arrays
- `printf()` and `scanf()`

## Learning Objectives

After completing this section, learners should be able to:

- Understand the differences between the four number systems.
- Convert integers between different number systems.
- Use C format specifiers to display numeric values in different bases.
- Implement conversion logic using loops, arithmetic, and bitwise operations.
- Validate input according to the expected number system.

## Note

These examples focus on integer number conversion. Floating-point number representation and conversions involving fractional parts are outside the scope of this section.

## Purpose

The goal of this section is to strengthen fundamental C programming skills through practical number system conversion programs.
