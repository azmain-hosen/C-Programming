# Conversions in C

This section covers different types of conversions in C programming, including type casting, temperature conversion, unit conversion, number system conversion, and character conversion.

Each category demonstrates how values can be converted from one representation or measurement unit to another using C programming concepts.

## Topics Covered

### 1. Type Casting

**Folder:** `01-type_casting/`

- Integer to float
- Float to integer
- Integer to character
- Character to integer
- Explicit type casting using the cast operator

### 2. Temperature Conversion

**Folder:** `02-temperature_conversion/`

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Celsius to Kelvin
- Kelvin to Celsius
- Fahrenheit to Kelvin
- Kelvin to Fahrenheit

These programs use arithmetic expressions and temperature conversion formulas.

### 3. Unit Conversion

**Folder:** `03-unit_conversion/`

This category covers common measurement conversions across six groups:

- **Length:** Kilometer, meter, centimeter, and millimeter
- **Mass:** Kilogram, gram, and milligram
- **Time:** Hours, minutes, and seconds
- **Speed:** Kilometers per hour and meters per second
- **Area:** Square meters and square centimeters
- **Volume:** Liters and milliliters

The `03-unit_conversion/README.md` file documents these categories and their conversion programs.

### 4. Number System Conversion

**Folder:** `04-number_system_conversion/`

Conversions between four common number systems:

- Decimal (base 10)
- Binary (base 2)
- Octal (base 8)
- Hexadecimal (base 16)

This category includes conversions between these number systems using formatting, arithmetic operations, and bitwise techniques.

### 5. Character Conversion

**Folder:** `05-character_conversion/`

- ASCII code to character
- Character to ASCII code
- Lowercase to uppercase
- Uppercase to lowercase

These programs introduce character codes and ASCII-based character conversion.

After completing this section, learners should be able to:

- Convert values between fundamental C data types.
- Apply mathematical formulas to real-world conversion problems.

The goal of this section is to strengthen fundamental C programming skills through practical conversion programs and prepare for more advanced topics such as control flow, loops, functions, and problem solving.
